# Earlier visual concepts ("Ummless", Claude Design canvas)

Source: `Ummless_communication_skills_app.pdf` and the Claude Design canvas it was exported from. The product
owner **did not like the visual style** (dark ink + acid lime, brutalist type) and asked us to explore a new
direction. We kept the useful *ideas*, re-scoped them to the Notion spec, and dropped what conflicts with it.

## Screen inventory and what we did with each

| # | Concept screen | Kept? | Where it lives now |
| --- | --- | --- | --- |
| 1a | Mirror Test (front camera, live eye-contact/pace/fillers) | Partly | Guided assessment is voice-only (no camera — the spec measures 7 verbal dimensions; camera adds a permission and anxiety). Live level meter + suggestion timer. |
| 1b | Voice DNA (score 612, level, archetype) | Reworked | **No overall score** (spec). Per-dimension levels + evidence confidence, "Not enough evidence yet", provisional style description. |
| 1c | Today — personalized plan | Yes | Today tab: "Start today's mission" + 2‑minute option, weekly target ring, upcoming event. |
| 1d | AI Spar with live coach whisper | Yes | Practice → Spar: personas, Kind/Real/Brutal, coach whisper between turns, report. |
| 1e / 2a–2f | Arenas, community, pods, connect, events, DMs | Deferred | Social layer needs a user base + moderation + real-time infra; not in the Notion spec. Backend is structured so it can be added later. |
| 1f | Pod of five | Deferred | Same as above. |
| 1g / 3h | Talks + "Steal their style" + shadow mode | Yes | Practice → Talks: public-domain speeches and original exemplar scripts, AI breakdown, line-by-line shadowing with on-device rhythm match. |
| 1h | Wingman earpiece coach in live meetings | Reworked | Real-time whispers need live diarization we can't do reliably. Shipped instead: **record a meeting → debrief** (who spoke, best moment, decisions, follow-up summary). |
| 3a | Welcome | Reworked | New brand + copy, honest about time (10–15 min) and choices. |
| 3b | Onboarding goals + minutes/day | Reworked | Spec questions: rank contexts, "what should feel easier", language, goal area. Weekly target replaces minutes/day. |
| 3c | Test intro: 3 challenges, camera | Reworked | Five spec activities, voice-only, time shown up front. |
| 3d | 30-day plan 612 → 720 | Reworked | Course map by module; labeled "Tailored to your profile" or "Based on your goal". No score targets. |
| 3e | Spar persona + scenario + Clone Mode | Partly | Personas + custom scenarios kept. **Clone Mode dropped**: cloning a real person's voice without their consent is an ethical and legal problem. "Describe the person" emulates behaviour, not voice. |
| 3f | Spar report (B+, rewrite this moment) | Reworked | No letter grades. Outcome, momentum, and "Rewrite this moment" (you said → try instead). |
| 3g | Live debate room | Deferred | Social/real-time. |
| 3i | IRL quest | Yes | Real-life missions in the course with reflection (reflection informs goals; it is not skill evidence). |
| 3j | Wingman debrief | Yes | Meeting debrief on recorded/uploaded conversations. |
| 3k | Profile / Voice Passport 668 | Reworked | Progress tab: communication web, practice stats kept separate from skill, milestones. |
| 3l | Leagues leaderboard | Dropped | Competes on XP, which conflicts with "keep practice completion separate from skill" and the spec's calmer motivation model. |
| 3m | Notifications inbox | Partly | Optional local reminders on user-chosen days. |
| 3n | Membership $14.99 / $7.99 yearly | Yes | Paywall after the free baseline + one free task + course preview. Price shown before purchase; labeled as a hypothesis in config. |
